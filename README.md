# WeatherApp

A simple weather app built with HTML, CSS, and JavaScript. Search for a city to see its current weather and a five-day forecast.

## Features

- Search for weather by city name
- View temperature, humidity, and wind speed
- Switch between Celsius and Fahrenheit
- View a five-day weather forecast
- Weather condition icons and a responsive layout

## Getting Started

1. Get an API key from OpenWeatherMap.
2. Replace `YOUR_OPENWEATHER_API_KEY` in `index.html` with your API key.
3. Open `index.html` in your browser.

The app uses the OpenWeatherMap API for current weather and forecast data. No additional packages or build steps are required.

> **About API keys:** Keys used in browser-based apps are visible in the source code. Do not push your API key to a public repository. Where possible, configure usage restrictions in your OpenWeatherMap account.
